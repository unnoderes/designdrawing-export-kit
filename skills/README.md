# Skills

This directory contains the independent diagram rendering skills.

## mermaid-render

Render Mermaid diagrams (.mmd) to SVG/PNG/PDF using Chromium-backed Puppeteer.

## plantuml-render

Render PlantUML diagrams (.puml) to PNG/SVG/PDF/EPS using Java runtime.

Each skill is self-contained with its own `SKILL.md`, scripts, and utilities.
