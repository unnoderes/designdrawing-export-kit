## 1.0.0 (2026-05-16)

### Features

- **mermaid-render**: Environment pre-checks, auto browser discovery (Chrome/Edge/Chromium), auto puppeteer config, CLI and programmatic API.
- **plantuml-render**: Environment pre-checks (Java, Graphviz, plantuml.jar), auto-download jar, multiple output formats (png, svg, pdf, eps).

### Repository

- Monorepo structure following `orchestration-skills-kit` conventions.
- Root `SKILL.md` aggregates both sub-skills.
- `.claude-plugin` and `.codex-plugin` metadata included.
